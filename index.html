    三步做个玩偶

    1 · 皮肤　拖入 64×64 或 64×32 的皮肤 PNG。尺寸不是这两档会直接提示，不会让你对着一个坏模型猜。

    2 · 体型　细胳膊是 Alex（3 像素手臂），经典是 Steve（4 像素）。皮肤手臂被裁了一条边，就是选错了。

    3 · 导出　GLB 最省事；要进 Blender / Unity 用 FBX；OBJ 给只认纯几何的老软件。glTF 会打包成 zip，里面是 json + bin + png。

    骨骼来自《森罗物语：玩偶工坊》的坐姿几何，也可以导入自定义 json 模型。

    保存前看一眼

    模型和预览图都是走浏览器的下载能力保存的。如果你是在 B站 App 里打开这个玩具，App 内置网页一般不给下载权限，点了会没反应、也找不到文件。

    解决办法：点右上角 ··· 菜单，选 在浏览器中打开， 再回来点导出，文件就会正常存到「下载」目录。

    保存预览图
